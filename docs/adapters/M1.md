## 3. 外置加载合同（PDE 已实现；PINN 组件有限验证）

外部 clone、必要兼容依赖和任何生成的适配缓存必须位于 GitHub 候选与 Zenodo 数据包之外。接口应要求显式源路径，不自动寻找正式项目/临时项目里的旧副本，不联网自动下载，不退回较新上游版本。

独立子进程启动前检查：固定提交、目标文件 SHA-256、允许的依赖版本、输入数据身份、输出目录不存在。源文件只读；原始字节身份和实际适配规则都记入本次运行记录。用户取得外部源码的方式不会自动解决该源码的再分发授权问题。

接口职责如下；PDE/GIFT命令见第7节，PINN参考终态快速读取见第9节；KC独立训练/续算见 [PINN_PHASE_SCHEDULER.md](PINN_PHASE_SCHEDULER.md)，仅NAdam原语边界见第8节。Open完整训练不可执行。

| 独立操作 | 行为合同 |
| --- | --- |
| PINN `train` | 一个指定噪声/库配置，一个全新任务；从未训练初始化开始，完整固定预算；不要求与其他模型同一个 run。 |
| PINN `resume` | 仅续接同一个任务的最近有效状态；验证源、数据、配置、参数与优化器状态、阶段和累计预算；不能拿其他任务或发布权重代替自身状态。 |
| PDE-FIND `fit` | 单独进行已固定的预处理、候选库构造和稀疏回归；不是神经网络训练，不虚构神经优化器检查点。 |
| M1 `use-results` | 只读取已存在的结果及其真实状态；字节验证后提取系数/CSV；不训练、不前向推理、不把失败报告改成成功。 |

新接口不能伪造旧公开入口的 COMPLETE/manifest，也不能声称旧执行记录属于新接口。新 PDE 每个 method/condition 自己有独立的 `gift.independent-m1-job` 记录和原子提交；其 complete 只表示该任务计算完成，不表示原五方法实验完成或原数值验收通过。导入成功仅证明可导入，不证明训练、续算或数值等价。

## 4. PINN-SR 最小但不可省略的适配

### 4.1 为什么不能直接 import 上游脚本

所选源文件在顶层设置 `CUDA_VISIBLE_DEVICES=0`，将类放在 `tf.device` 块内，类构造器创建 TF1 Session；还包含原数据、训练和输出流程。不能整体 import 后让原脚本自行开始工作。新加载器可在精确源哈希检查后，从外部源码的 AST 中选择所需定义，显式提供依赖与初始化环境；不得把选中的第三方函数体保存到 GitHub 或数据包。

AST 选择并不能消除适配工作：原脚本对应 60 项候选库，当前 M1 使用 90 项开放库及 4 项 KC 库；又有周期域数据、TF2.10 兼容、分块微分和阶段续算差异。应记录明确且有限的转换规则与结构断言，不能通过字符串大段替换夹带第三方实现，也不能声称这已经由一个简短 loader 完成。KC已有小预算真实联动与一次新进程续算验证，完整预算验收仍未完成；Open保持单独阻断。

### 4.2 必须保持的数学和数据设置

| 项目 | 旧实验的固定合同 |
| --- | --- |
| 数据/随机设计 | 训练轨迹 0；seed 1234；500 空间传感器 × 60 时刻；观测 80/20 划分；60000 LHS 配点加 24000 训练观测，共 84000 物理行。噪声/库配置间坐标、划分、配点和未训练网络参数相同。 |
| 观测适配 | 所有方法从同一含噪涡量出发，周期 Biot–Savart 重建速度；不沿用原圆柱例子分别加噪的速度观测，也不混入干净真值速度。 |
| 网络 | 8 个隐藏层，每层 60 个 tanh 单元；输入坐标，输出 `(u,v,w)`；每个新任务使用全新图和优化器状态。 |
| 候选库 | 开放库 90 项；KC 仅限制候选坐标为 `w`、`u*w_x+v*w_y`、`w_xx+w_yy`、`q`，不提供真值、符号、系数范围或非零掩码。KC 是本项目受限配置，不标作上游独立新算法。 |
| 参数读取 | 对 KC 系数映射：alpha 是 `w` 系数的负值，beta 是对流项系数的负值，nu 是扩散项系数，gamma 是 `q` 系数。候选/系数顺序必须显式固定。 |
| 优化预算 | 5000 NAdam；L-BFGS-B 的 `maxiter=maxfun=10000`；6 轮 STRidge 后各接 1000 次网络与系数联合 NAdam；最后 20000 NAdam。不能把联合阶段误改成只更新网络。 |
| L-BFGS-B | `maxcor=maxls=50`、`gtol=1e-5`、`ftol=0.1*float64_epsilon`；记录实际求值、迭代、线搜索和退出原因，不能只比较最大预算。 |
| 精度/分块 | TF 图 float32；优化器接口的参数/梯度提升至 float64；STRidge 使用 complex64；固定微分分块 32768。不能因“高精度更好”而改为全 float64。 |
| 环境 | 保留该方法实际 TF2.10 兼容执行、TF1.15 NAdam 语义及已记录的 TF32/BLAS 线程设置；不要套用别的模型的全局环境开关。依赖升级须重新验等价。 |

### 4.3 未训练初始化文件与自身续算的区别

外置数据包预定位置为 `auxiliary/pinn_initialization/network_initialization_tf115_seed1234.npz`：98817 字节，SHA-256 `AB0834A1494D2D46E0CBC8A4E24D29DE91B5F10EAD97F7DB6990A0C302D990CB`。

已读旧实现的 `export_tf115_initialization`：强制 TensorFlow 1.15.0，在禁用 GPU 的 Session 中仅初始化变量并导出网络变量；不调用训练器。文件含 18 个 float32 网络权重/偏置数组，不是训练后权重，也不含可用于偷跳预算的优化器终点状态。将其用作固定随机起点应明确披露，不能称为重新运行当前 TF 随机生成器后必然得到同一结果。

文件生成方法可定位，但本次没有重新生成它；原生成代码的混合来源与该数值文件的发布权利尚未最终审定。外置包 provenance 应保留 `untrained`、来源待完善/权利待确认，不标为项目独占权利。未训练初始化不能替代完整的自身续算状态。

### 4.4 完整训练已完成但关键数值验收失败

旧执行已出现PINN-SR-KC/noise001的gamma派生指标超差。本候选新的独立GPU run随后完成全部原预算：5000预NAdam、原L-BFGS预算、6轮各1000步ADO、20000步post，共31000次NAdam/6次STRidge，rc0、3433.60秒。源、输入、预算、同run终态NPZ/JSON/完成提交的校验均通过；实际系数×mask读出后，原三行12个数值有2项失败，三个estimate本身均通过。失败字段为gamma的absolute_error（新0.21602565050125122，原0.23254746198654175）与relative_error_percent（新21.602565050125122%，原23.254746198654175%）；仍逐字段使用`0.0005+0.05*abs(reference)`，没有改真值或原结果。

本次保存状态只读比较：pre-NAdam5000边界60个主状态及22个诊断累积器全部exact；L-BFGS结束、首轮STRidge之前，18个网络张量与1个系数张量不同，38个NAdam槽、2个beta及mask仍exact。当前/原LBF都按相同相对函数下降条件终止，但迭代分别1356/1046、已完成函数/梯度求值1423/1075。两边参数与梯度均按`W0,b0,...,W8,b8,coefficients`打包，顺序不同这一怀疑已排除。证据只定位到L-BFGS阶段内，不是首个浮点分歧或具体原因；原`scipy.optimize.minimize`、`setulb`续算控制和环境数值路径的贡献尚未分离，不能断言包装器有bug或归因为随机性/TF。`gradient_l2`仅日志值，不是优化器输入。旧82变量中含诊断累积器的计数，不应与本次19个模型张量差混用。

完整训练与差异证据保留，不据此自动重训、反复扩大诊断、放宽容差或替换参照。gamma更接近真值也不豁免对报告误差列的复现门槛。见 [完整训练失败旁证](../../validation/fresh_20260910/pinn_known_noise_001/README.md)及 [保存边界比较](../../validation/fresh_20260910/pinn_known_noise_001/boundary_comparisons.json)；这些小文件不分发终态权重、TF图或训练journal。

## 5. PDE-FIND 最小适配

1. 校验外部 `PDE_FIND.py` 后，在隔离子进程加载上游 `TrainSTRidge`、`STRidge` 和 `build_Theta`。不要在候选中保留这些函数的复制、向量化重写或整份旧 runner；也不要换成 PySINDy 后称为同一原实现。
2. 原创数据接口只负责共同观测、周期速度重建、预处理、导数数组与明确的行/列顺序；开放库交给上游 `build_Theta`。小数组验等价必须同时检查完整列描述、列值、顺序和 dtype，而非只检查列数等于 90。
3. 对 NumPy 2 的旧 `biginds != []` 兼容问题，原 runner 仅在已哈希的外部 STRidge 源中将该空集合判断改为长度判断，并要求恰好命中一次。新接口可以采用同等有限的内存规则并记录，不能展开整个算法体；若采用旧 NumPy 避免该转换，也必须单独验证数值环境等价，不能静默换版本。
4. 原内部随机划分必须保持；旧 runner 的集合成员判断加速不改变所抽取的样本值，但临时修改共享 NumPy 对象，应隔离在一个子进程。移除此加速也需确认采样序列与矩阵顺序不变。
5. 完整回归前的小测试只用于适配正确性，不可替代完整数据与原容差验收。

固定设置：训练轨迹 0，64×64 的 4096 个空间点 × 60 时层；五次局部多项式，时间/y 窗口 9，x 窗口 19，空间周期包裹。干净数据不做 SVD；1%/10% 噪声固定涡量秩 26、速度分量秩 20。10% 是对上游 0%/1% 例子的明确外推，不隐去此区别。回归保持 `lambda=1e-5`、`d_tol=5`、`maxit=25`、`STR_iters=10`、`split=0.8` 和上游内部 seed 0；开放/KC 使用同一状态、导数与行集合，库矩阵保持 complex64。禁止按真值改变阈值、符号、边界或筛选回归输出。

## 8. 新 PINN NAdam 原语：明确不是完整 PINN 训练

独立实现是 `adapters/pinn_runtime.py`，环境与命令见 [PINN_ENVIRONMENT.md](PINN_ENVIRONMENT.md)。没有复制外部网络、STRidge、NAdam、Scipy类body；只读取用户pinned clone的已哈希定义。M1中PINN的 `--execute` 是另外的参考终态快速读取，不会以此NAdam原语偷换完整从零训练。

最小适配包括：精确修改一个系数维度节点；把原 `net_U` 联合坐标张量标记给梯度适配器，共用联合梯度再切出 x/y/t；保留外部原 60 列循环，由小量项目几何 glue 加 30 列 forcing 或 KC 四列；对一个一元幂节点用原 tensor / 乘法表达固定一次与二次项。损失使用当前实验的三个输出联合归约、分项 float32 梯度累加后除总损失，再调用**外部官方** NAdam。

GPU02另对KC外置mask placeholder精确增加静态 `shape=[4,1]`（唯一命中，否则拒绝）；这是消除GPU01仅4项系数梯度差的唯一计算修正，不修改open、不调整精度或容差。两tiny案例各全部26047个梯度元素及更新exact；全24000观测/84000物理行、chunk32768的单次更新亦exact（19.396秒）。tiny全FSM及L-BFGS边界不同进程续算的全部81变量和科学trace exact。三份实际RESULT身份及环境命令见 [GPU验证边界](PINN_ENVIRONMENT.md#kc-gpu-三项有界验证与独立启动)，这些检查不认证完整非凸训练或历史L-BFGS漂移已解决。

第一轮非零系数小测试两模式失败；共享联合梯度后 KC 全通过，open 仍失败；最后将 Pow 反传换成旧图的 Mul 后，open 仍有 160 个完整梯度元素不完全相同。已达到两次有限数值修正后停止，不能把最后一次改动说成已解决原因。剩余差异可能与开放库分支的浮点累加图有关，但尚未定位具体操作；不是随机性结论，也不是允许忽略误差的理由。

之后另做了一次隔离CPU试验：只将open mask静态shape补为`[90,1]`，相对旧图仍是160/26133梯度元素不相同、最大2.3283064365386963e-10，且3个更新参数张量不相同；没有改善，失败后停止，未集成源码或放宽门禁。该小试验没有运行完整训练。

仅NAdam独立阶段CLI与新的完整阶段控制器都只允许known/KC；open在读实验数据或构图之前拒绝，保留计划和有界图诊断API。尚未证明上述微小梯度差会造成报告级偏差，更不能把其他PINN问题都归于它。完整ADO/L-BFGS已通过KC tiny联动，noise001/KC正式GPU训练也已完成，但原终态比较2/12失败；可显式执行不代表正式训练已合格。

`NAdamCheckpoints` 仅使用 `allow_pickle=False` 的 NPZ 与 JSON，保存所有 81 个 TF 全局状态变量（网络、系数、m/v、beta powers、累加器/分项计数）、独立 mask、迭代数及 Python/NumPy RNG。此 NAdam 图在规范初始化后没有随机训练操作，不能据此声称实现了任意随机 TF 图的 RNG 恢复。输入初始化、采样、同噪声数据文件 SHA、来源、配置和数值环境严格绑定；源码或配置变化不能继承旧测试目录。

## 9. 已恢复训练终态的独立 PINN 快速读取

`adapters/pinn_reference.py` 从 `artifacts/pinn_reference` 中六套数值终态读取实际系数；这些不是新训练器的续算检查点。目录按noise_000/noise_001/noise_010及open/known区分，各NPZ含82个已核验float32数组，包括网络、原优化器状态、系数和mask；没有TF `.meta`图或外部算法源码。总manifest固定SHA为 `E061310F528E864034FECF79B641AB65272F05EE51D8FCCDB51B499E26955D15`。

入口先核manifest、模式/条件、NPZ路径/字节数/SHA与原观测H5的SHA绑定；读取器再核全部82数组的名字/形状/dtype/逐数组SHA/有限值及0/1 mask，才由 **实际 `coefficients * mask`** 计算参数。它不相信manifest里可选的parameters字段。Open取两扩散坐标均值为nu、两对流坐标均值的负值为beta、q为gamma；KC直接取扩散项、对流项负值和q。原生CSV保留完整90/4项有效系数，不只写三个参数。
