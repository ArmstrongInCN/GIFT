# 外部算法边界与一致性验证

GIFT 的工作目录不保存外部算法源码、复制的算法实现、可执行源码补丁或自动源码改写器。官方仓库、固定版本与必要的手工适配操作见 [外部算法适配说明](EXTERNAL_MANUAL_ADAPTATION.md)。`adapters/__init__.py` 仅提供通用路径解析、模块连接和发布元数据处理；外部方法的网络、求解器、源码加载与适配实现均位于仓库之外。

本机已用于实验的外部接口位于 `D:/2_GIFT/gift-external-runtime/`，原官方源码目录保持原位。运行时可以通过 `GIFT_EXTERNAL_ADAPTER_ROOT` 指定外部接口目录；该目录及其实际解析路径不得位于 GIFT 内。重新取得 GIFT 的使用者需要在仓库外下载官方代码、按文字说明适配并提供接口。训练入口、评价协议及 GIFT 自身算法仍保留在 GIFT 中。

已发布结果中的源码补丁原文不再保留。移除范围仅限补丁说明的 `before`、`after` 字段，及受这些文件字节变化影响的哈希、字节数引用；实验指标、训练设置、预测数组与图像没有重算或修改。原始元数据、原始运行记录与迁移验证证据保存在仓库外的 `D:/2_GIFT/repository_audits/external_boundary_20261007/`。

这些检查支持本次目录整理没有改变已验证的程序计算与既有实验结果。它们包括 CPU 固定输入测试和算法结构对照，没有重新执行完整 GPU 训练，也不声称证明所有设备和所有输入下的逐位确定性。

从 GIFT 根目录执行 `python -B -m scripts.audit_repository`，检查当前拟发布工作文件的边界。该命令拒绝仓库内外部实现目录、算法定义和 JSON 中的源码补丁字段。目录中的忽略文件和缓存另作实际文件扫描，不能仅依赖 Git 文件选择。

本次整理通过移动保留外部实现与旧缓存，未批量删除文件。Git 提交和历史未重写；旧版本记录不属于当前工作文件边界。发布本次工作文件前，必须将移出的旧适配文件删除记录与通用接口、说明文档一起提交，不能仅提交新增说明。
